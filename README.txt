# Власний блокчейн з нуля (Практична робота № 1)

Прототип криптовалюти та блокчейн-мережі мовою Python без використання готових блокчейн-фреймворків.

## Можливості
- Генерація гаманців ECDSA (secp256k1) та цифровий підпис транзакцій.
- Черга непідтверджених транзакцій (Мемпул) із 4 перевірками (підпис, баланс, nonce, дублікати).
- Власна реалізація Дерева Меркла (Merkle Tree).
- Майнінг Proof of Work (PoW) з автоматичним коригуванням складності.
- REST API на Flask для запуску мережевих вузлів.
- Синхронізація мережі з 3+ вузлів та розв'язання розвилок (консенсус за найдовшим ланцюгом).
- Захист від 5 основних типів атак.
